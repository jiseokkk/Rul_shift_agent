# Tier-1 — draft Case C 문제와 그 해법

## 1. draft Case C의 문제점 (자연 이동에서의 실패)

**상황**: Direction B(자연적 비행클래스 이동, unit 14 = Fc1). 주입 없이 실제로 다른 비행클래스라 **모든 센서가 학습 기준(Fc3)에서 벗어남**(mean |z| ≈ 1.6). 그런데 RUL 모델은 사실 잘 일반화(예측 편향 −1.4). → **오경보에 강해야 하는** 조건.

**에이전트 오류가 여기 집중됨:**
| 구간 | 오류 | 원인 |
|---|---|---|
| 초기(cyc 22–37) | **오경보 4건** | 여러 채널 편차를 *adverse 센서 이동*으로 오인 (context에 "다른 flight class"라고 있는데도 무시, 투표 만장일치 "adverse") |
| 후기(cyc 52–58) | **미탐 3건** | 같은 편차를 *favorable*로 오귀속 → Continue 선택 (Inspect가 맞는데) |

**근본 원인**: draft 에이전트는 사실상 **전역 z-score(marginal)** 만 봄. 그래서
> **"운전조건 때문에 생긴 편차"(profile-induced)** vs **"실제 열화/결함 편차"(degradation-induced)** 가 크기가 겹치면 **방향 귀속이 불가능**.

즉 "다른 비행클래스"와 "센서 문제"를 구분할 신호가 없음 → 오경보(FPR 0.14)와 유일한 미탐(FNR 0.17)이 모두 여기서 발생.

**draft가 스스로 제안한 처방**: *flight-class-conditioned baselines (per-class z-scores)* — 즉 **비행클래스별 기준분포로 조건화하라.** ← Tier-1이 이걸 일반화·구현한 것.

---

## 2. Tier-1 설명 (Case C를 어떻게 푸는가)

전역 z 대신 **원인을 가르는 조건부 신호**를 준다. 셋 다 Fc3 학습으로만 fit한 **선형/다항 회귀**(신경망 아님).

### #1 `regime_z` — 운전조건 조건부 z (draft 제안의 일반화)
- **무엇**: "지금 **운전점(W=고도·마하·스로틀·흡입온도)** 을 감안하면 이 센서가 정상인가"
- **왜 Case C를 푸나**: 다른 비행클래스는 *W 분포* 가 다를 뿐 물리 규칙은 그대로 → W로 조건화하면 **자연 이동이 상쇄돼 regime_z가 작아짐** → 오경보 사라짐. (draft의 per-class 기준을 **이산 클래스가 아니라 연속 W**로 확장한 것)
- **어떻게**: `E[센서|W]`를 다항회귀로 학습 → `regime_z = (관측−기대)/잔차std`. **부호가 방향**(음수=adverse, 양수=favorable)까지 알려줘 오귀속 해결.

### #2 `consistency_z` — 채널간 물리 일관성 (방향 귀속 근본 해결)
- **무엇**: "센서들끼리 서로 말이 맞나" (`E[센서_j | 나머지 센서들]`의 잔차)
- **왜 Case C를 푸나**: 비행클래스 변화는 **모든 채널이 함께** 물리 곡면 따라 이동 → 여전히 서로 맞음 → 작음. 실제 센서 결함은 일부만 튐 → 큼. → **"운전조건 편차"와 "결함 편차"를 물리로 분리** (Case C 근본원인 제거).
- **어떻게**: 다른 센서들로 각 센서 예측 → 잔차 정규화.

### #3 `mc_std` — 모델 자신의 불확실성
- **무엇/왜**: dropout 30회 예측 편차. OOD에서 상승. 센서통계와 **독립** 보조 근거.

### 실측 — 자연 이동에선 잠잠, 실제 바이어스엔 폭발
| 지표 | natural(Fc1, Case C 상황) | adverse(센서 바이어스) |
|---|---|---|
| temp z_global (전역, draft가 보던 것) | +0.58 (큼→오경보 유발) | −1.69 |
| **regime_z (#1)** | **−0.55 (작음)** | **−62.5 (폭발)** |
| **consistency_z (#2)** | **0.52 (작음)** | **15.6 (폭발)** |

→ **draft가 헷갈린 바로 그 자연 이동에서 Tier-1은 작게 유지** → 오경보/오귀속 사라짐.

### 효과
| | draft(전역 z) | Tier-1 적용 |
|---|---|---|
| natural FPR | 0.14 | **0.00** |
| natural 미탐(FNR) | 0.17 | 0.06 |
| Ablation | — | Tier-1 전부 제거 시 FPR **0.65**로 Case C 실패 재현 / consistency 제거 시 adverse 탐지 붕괴 |

**한 줄**: Case C는 "운전조건 편차 vs 결함 편차"를 전역 z만으로 못 갈라서 생긴 오경보·오귀속이었고, **Tier-1(#1 운전조건 조건화 + #2 채널간 일관성)이 그 둘을 원인 수준에서 분리**해 해결한다.
